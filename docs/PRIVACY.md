# Privacy

Last updated: 2026-08-15

Unvirtual Display is a local-only desktop application.

- It does not require or provide an account or login.
- It does not upload imported models, images, projects, or screenshots.
- It does not collect analytics, telemetry, advertising identifiers, or crash reports.
- It does not connect to model stores or payment services from inside the app.
- Imported files are copied into the active project's local asset directory.
- Diagnostic messages are kept in memory for the current app session. A text file is created only when the user explicitly chooses **Export diagnostics**.
- `.uvd` backups and PNG captures are written only to the location selected by the user.

The operating system, itch.io, or the web browser used to download the app can process data under their own policies. Those services are outside Unvirtual Display.
